# 基金从业资格考试题库（科目一 + 科目三）

移动端优先的免费刷题页面，覆盖 2026 版考试大纲：

| 科目 | 章节 | 题量 |
|---|---|---|
| 科目一《基金基础知识与法律法规》 | 8 章 | 219 题 |
| 科目三《私募股权投资基金基础知识》 | 9 章 | 200 题 |
| **合计** | 17 章 | **419 题** |

## 在线使用

- 刷题：打开本仓库 Pages 首页即可
- 考点速览：`points.html`

## 功能

- 按科目、章节筛选；只看错题；乱序刷题；清空记录
- 点选项即判对错并显示解析；键盘 A/B/C/D 选择、←/→ 翻题
- 进度、正确率、错题数统计；作答记录保存在浏览器本地（localStorage），关掉再开不丢

## 说明

题目为按考纲与考生笔记自行编写的仿真练习题，用于知识点自测，**不是历年真题**，也不代表官方命题。数字、时限类考点已按 2026 版大纲与法规口径核对，如遇官方教材更新请以中基协最新大纲为准。

考试信息（以官方为准）：中国证券投资基金业协会 <https://www.amac.org.cn/>，报名 <https://baoming.amac.org.cn/>。
